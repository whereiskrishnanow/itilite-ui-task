# itilite home dashboard

A pixel-matched rebuild of the itilite admin home screen (React + Vite, Inter Display),
with interaction details: collapsible sidebar rail with flyouts and tooltips, an Iris banner
with animated reflections, spend tabs with rolling numbers, quick actions with icon motion,
and a help popover.

Live: https://whereiskrishnanow.github.io/itilite-ui-task/

```bash
npm install
npm run dev      # http://localhost:5178
npm run deploy   # builds for /itilite-ui-task/ and publishes to the gh-pages branch
```
